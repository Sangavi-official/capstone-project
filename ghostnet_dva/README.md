# GhostNet DVA — Data Visualization & Analytics Mini Project

## What This Is
Primary data collection and analysis mini project built on top of the GhostNet
RL-MTD system. Data is generated by running the trained PPO agent through 500
episodes and logging 15 variables per episode.

## Folder Structure
```
ghostnet_dva/
├── data_collection/
│   └── generate_dataset.py     ← STEP 1: Run this first
├── dataset/
│   └── ghostnet_primary_data.csv  ← Auto-created after Step 1
├── analysis/
│   ├── analysis.py             ← STEP 2: Run this second
│   └── visualizations/         ← 8 charts saved here
└── report/
    └── dva_insights.txt        ← Auto-written insights
```

## Dataset Columns (15 total)

| Column | Type | What It Captures |
|--------|------|-----------------|
| episode | int | Episode number (1–500) |
| timestamp_sec | float | Elapsed time in seconds |
| total_reward | float | Defense performance score |
| steps_completed | int | Steps before episode ended |
| defense_efficiency_pct | float | Reward as % of max (190) |
| cve_score | float | Live threat level 0.0–1.0 |
| threat_level | str | LOW / MEDIUM / HIGH / CRITICAL |
| recon_events | int | Attacker recon detections |
| dominant_action | int | Most-used action (0–5) |
| dominant_action_name | str | Action label |
| action_diversity | int | Unique actions used (1–6) |
| cloud_mutations | int | Cloud layer mutation count |
| iot_mutations | int | IoT layer mutation count |
| api_mutations | int | API endpoint rotations (AESM) |
| traffic_disruption_avg | float | Avg patient traffic impact |
| traffic_disruption_max | float | Worst traffic disruption |
| cloud_ip_changed | int | Cloud IP rotated? (0/1) |
| iot_ip_changed | int | IoT IP rotated? (0/1) |

## Why This Is Valid Primary Data

Primary data = data you collected yourself, for your specific research purpose,
that did not exist before you created it.

This dataset was generated by:
- Designing the simulation environment (GhostNet)
- Training the RL agent yourself (PPO, 100,000 steps)
- Running 500 controlled episodes with deliberate variable logging
- No external dataset was downloaded or reused

This is equivalent to running a lab experiment and recording the results.

## Charts Produced (8 total)

1. Defense efficiency over 500 episodes (line chart)

4. Cloud vs IoT mutations by threat level (grouped bar)
5. Patient traffic disruption over time (line chart)
6. Reward distribution across all episodes (histogram)
7. Variable correlation matrix (heatmap)
8. Action diversity vs reward (scatter + box plot)
